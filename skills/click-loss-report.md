# Click Loss Report Process - Bright Forge SEO

## Report Purpose
Identify pages losing organic traffic and clicks, diagnose causes, and provide actionable recommendations for recovery.

## Data Collection Period
- Primary: Last 3-6 months
- Comparison: Year-over-year where available
- Segment: Month-by-month trends
