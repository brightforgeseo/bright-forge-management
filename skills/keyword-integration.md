# Keyword Integration Rules - Bright Forge SEO

## CRITICAL RULES

### Primary Keyword (PK)
**Identification:**
- Extract from article title
- Must have HIGH relevance to both title AND article content

**Usage Requirements:**
- 3-5x in body content ONLY
- Count body separately from metadata
- Distribute across: intro, body paragraphs, H3 headings, conclusion
- Natural integration - never forced

**Metadata (separate count):**
- Meta title: 1x
- Meta description: 1x
- H1 (title): 1x (doesn't count toward body requirement)

### Secondary Keywords (SK)
**Identification:**
- 4-6 topically relevant keywords
- Support the primary keyword theme
- NEVER repeat across cluster articles

**Usage Requirements:**
- 2-4x each in body content
- Distribute naturally throughout
- Different SKs for each article in a cluster

### Keyword Placement Strategy
**Introduction (first 100-150 words):**
- PK: 1x naturally worked in
- SK: 1-2 secondary keywords

**Body Content:**
- PK: 2-3x distributed across sections
- SK: Spread evenly, 2-4x each
- Work into H3 headings where natural

**Conclusion:**
- PK: 1x reinforcement
- SK: 1-2 instances

## Verification Process
Before finalizing any article:
1. Count PK instances in body only (target: 3-5x)
2. Count each SK instance (target: 2-4x each)
3. Verify NO keyword repeats across cluster
4. Check metadata separately (1-2x)
5. Confirm natural integration, not stuffing

## Common Mistakes to Avoid
- ❌ Counting title/H1 toward body count
- ❌ Counting meta description toward body count
- ❌ Using same SKs across multiple articles
- ❌ Forcing keywords unnaturally
- ❌ Under-counting or over-counting
