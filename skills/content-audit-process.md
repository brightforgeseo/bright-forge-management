# Content Audit Process - Bright Forge SEO

## Audit Objectives
- Identify underperforming content
- Find optimization opportunities
- Discover content gaps
- Assess keyword targeting effectiveness
- Evaluate internal linking structure

## Data Collection Phase

### Performance Metrics (Google Analytics)
- Page views (last 3-6 months)
- Average time on page
- Bounce rate
- Conversion rate (if tracked)
- Traffic sources

### SEO Metrics (Google Search Console)
- Impressions
- Clicks
- Average position
- CTR
- Queries driving traffic

### Technical Analysis
- Page load speed
- Mobile usability
- Core Web Vitals
- Indexation status
- Crawl errors

## Prioritization Matrix

### High Priority (Do First)
- High traffic + declining
- Good rankings but low CTR
- Thin content on important topics
- Outdated information
- Broken or poor internal linking

### Medium Priority
- Moderate traffic, room for growth
- Decent rankings (positions 5-15)
- Content gaps vs competitors
- Missing optimizations

### Low Priority
- Low traffic, low potential
- Well-optimized already
- Less important topics
- Newer content (< 3 months)
