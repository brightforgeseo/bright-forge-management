# Client Onboarding Checklist - Bright Forge SEO

## Pre-Onboarding (Before Contract Signed)

### Discovery Call
- [ ] Understand business model and services
- [ ] Identify target audience
- [ ] Discuss business goals and KPIs
- [ ] Review current website and SEO efforts
- [ ] Discuss budget and expectations
- [ ] Explain our process and timeline
- [ ] Answer questions and address concerns

### Proposal & Contract
- [ ] SEO audit completed
- [ ] Proposal prepared and sent
- [ ] Contract prepared
- [ ] Pricing and terms agreed
- [ ] Contract signed by client
- [ ] First payment received
- [ ] Welcome email sent

---

## Week 1: Initial Setup & Access

### Administrative Setup
- [ ] Create client folder in management system
- [ ] Add client to project management tool
- [ ] Set up communication channels (Slack/Email)
- [ ] Add client to team calendar
- [ ] Create client brief document
- [ ] Assign primary account manager
- [ ] Schedule kick-off call

### Access & Credentials
- [ ] Website/CMS access
  - Platform: [WordPress/Shopify/etc]
  - Admin login credentials
  - FTP/hosting access (if needed)

- [ ] Google Analytics access
  - Property URL: [URL]
  - Admin or edit access granted
  - Goals and conversion tracking verified

- [ ] Google Search Console access
  - Property verified
  - Admin access granted
  - All versions added (www/non-www, http/https)

- [ ] Google Business Profile (if applicable)
  - Manager access granted
  - Verified listing

- [ ] Other tool access
  - Hosting account (if needed)
  - Social media accounts (if relevant)
  - Any existing SEO tools

### Documentation
- [ ] All credentials securely stored
- [ ] Access sheet created and shared with team
- [ ] Emergency contact information collected

## Red Flags to Watch For

During onboarding, watch for:
- [ ] Client slow to provide access
- [ ] Unrealistic expectations about timeline
- [ ] Previous SEO issues (penalties, black hat)
- [ ] Client wants guarantees on rankings
- [ ] Poor communication from client
- [ ] Lack of buy-in from stakeholders
- [ ] Budget concerns arising
- [ ] Scope creep starting

**Action if red flags:** Address immediately with client and account manager
