# Article Editing & Optimization Process - Bright Forge SEO

## Step 1: Initial Content Review
- Read full article for flow and coherence
- Check brand voice alignment
- Identify obvious AI language patterns
- Mark sections needing data/statistics
- Note structural issues

## Step 2: Keyword Optimization
**Use keyword-integration.md rules:**
1. Count primary keyword (target: 3-5x body)
2. Count secondary keywords (target: 2-4x each)
3. Verify no cluster keyword conflicts
4. Add/remove keywords as needed
5. Ensure natural distribution

## Step 3: Internal Linking
**Use linking-strategy.md framework:**
1. Identify which batch strategy applies
2. Select appropriate URLs to link
3. Create varied anchor text
4. Place links per strategy guidelines
5. Verify no duplicate URLs
6. Check against recent article patterns

## Step 4: Content Enhancement
- Replace generic statements with specifics
- Add statistics where claims made
- Include original source citations
- Break up long paragraphs
- Improve transitions between sections
- Strengthen intro hook
- Enhance conclusion with clear takeaways

## Step 5: Technical SEO Elements
**Meta Title:**
- Include primary keyword
- 50-60 characters
- Compelling and click-worthy
- Brand name at end (if space)

**Meta Description:**
- Include primary keyword
- 150-160 characters
- Clear value proposition
- Call to action

**H2/H3 Structure:**
- Logical hierarchy
- Keywords in some headings (not all)
- Descriptive and scannable
- Proper nesting

## Step 6: Quality Assurance
- [ ] All keywords integrated properly
- [ ] Internal links added per strategy
- [ ] No AI language patterns remain
- [ ] Statistics and data included
- [ ] Meta title/description optimized
- [ ] Headings properly structured
- [ ] Paragraphs scannable
- [ ] Brand voice consistent
- [ ] Actionable insights provided
- [ ] No grammar/spelling errors

## Step 7: Client-Specific Checks
- Review client's specific guidelines
- Verify industry terminology correct
- Check competitor differentiation
- Ensure regional language appropriate (AU/UK)
- Confirm brand messaging alignment

## Common Issues to Fix
- Generic AI conclusions
- Keyword stuffing or under-optimization
- Repeated linking patterns
- Missing data/statistics
- Poor transitions
- Weak introductions
- Vague recommendations
- Inconsistent voice
