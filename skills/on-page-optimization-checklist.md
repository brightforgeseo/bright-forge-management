# On-Page SEO Optimization Checklist - Bright Forge SEO

## URL Optimization

- [ ] Clean, readable URL structure
- [ ] Keywords in URL (when appropriate)
- [ ] Hyphens (not underscores) to separate words
- [ ] Lowercase URLs
- [ ] Short and descriptive (under 100 characters ideal)
- [ ] No special characters or spaces
- [ ] HTTPS (secure)
- [ ] Canonical tag implemented if needed
- [ ] No URL parameters (or minimal)

**Good:** yoursite.com/scaffolding-services-sydney
**Bad:** yoursite.com/page?id=123&cat=services

---

## Title Tag Optimization

- [ ] Unique on every page
- [ ] 50-60 characters (512 pixels max)
- [ ] Includes target keyword (preferably near beginning)
- [ ] Compelling and click-worthy
- [ ] Matches search intent
- [ ] Brand name included (usually at end)
- [ ] No keyword stuffing
- [ ] Accurately describes page content

**Template:** [Primary Keyword] | [Secondary Info] | [Brand Name]
**Example:** Scaffolding Hire Sydney | Professional Services | ACE Scaffolding

---

## Meta Description Optimization

- [ ] Unique on every page
- [ ] 150-160 characters (920 pixels max)
- [ ] Includes target keyword
- [ ] Compelling copy that encourages clicks
- [ ] Contains call-to-action
- [ ] Accurately describes page content
- [ ] No duplicate meta descriptions
- [ ] Benefits-focused

**Example:** "Professional scaffolding hire in Sydney. Fast delivery, competitive rates, safety certified. Get a free quote today. Call 02 XXXX XXXX."

---

## Heading Tags (H1-H6)

### H1 Tag
- [ ] One H1 per page
- [ ] Contains target keyword
- [ ] Descriptive and compelling
- [ ] 20-70 characters
- [ ] Matches or closely relates to title tag
- [ ] Clear and specific

### H2-H6 Tags
- [ ] Logical hierarchy (don't skip levels)
- [ ] Descriptive subheadings
- [ ] Keywords in some (but not all) headings
- [ ] Break up content logically
- [ ] Help readers scan content
- [ ] H2s every 300-500 words

---

## Content Optimization

### Quality Requirements
- [ ] Original content (not copied)
- [ ] Comprehensive and thorough
- [ ] Answers user's search intent
- [ ] Better than competing pages
- [ ] Provides unique value/insight
- [ ] Well-researched and accurate
- [ ] Up-to-date information
- [ ] Grammar and spelling correct

### Length Guidelines
- [ ] Sufficient word count for topic
  - Blog posts: 1,500-2,500 words
  - Pillar content: 3,000+ words
  - Service pages: 800-1,200 words
  - Product pages: 300-500 words
- [ ] Not artificially inflated
- [ ] Depth over length

### Keyword Integration
- [ ] Primary keyword: 3-5x in body
- [ ] Secondary keywords: 2-4x each
- [ ] Natural keyword placement
- [ ] Keywords in first 100 words
- [ ] Keywords in conclusion
- [ ] Keywords in subheadings (some)
- [ ] LSI/related keywords included
- [ ] No keyword stuffing

**Keyword Placement:**
- Introduction: 1x primary
- Body sections: 2-3x primary distributed
- Subheadings: Natural integration
- Conclusion: 1x primary

### Readability
- [ ] Short paragraphs (3-4 sentences)
- [ ] Short sentences (under 20 words average)
- [ ] Bullet points and lists
- [ ] Subheadings every 300 words
- [ ] White space for scannability
- [ ] Bold important points (sparingly)
- [ ] 8th-grade reading level or below
- [ ] Active voice preferred

### Content Structure
- [ ] Clear introduction
- [ ] Logical flow
- [ ] Organized sections
- [ ] Supporting details
- [ ] Examples/evidence
- [ ] Clear conclusion
- [ ] Call-to-action

## Image Optimization

### Image Best Practices
- [ ] Compressed and optimized
- [ ] Appropriate file format:
  - Photos: JPG or WebP
  - Graphics/logos: PNG or SVG
  - Icons: SVG
- [ ] File size under 200KB each
- [ ] Dimensions appropriate for use
- [ ] Responsive images
- [ ] Lazy loading implemented

### Alt Text
- [ ] All images have alt text
- [ ] Descriptive and specific
- [ ] Include keywords (when natural)
- [ ] 125 characters or less
- [ ] Don't start with "image of..."
- [ ] Decorative images: alt=""

**Good Alt Text:** "Worker installing scaffolding on commercial building in Sydney"
**Bad Alt Text:** "img_1234" or "scaffolding scaffolding scaffolding"

### File Names
- [ ] Descriptive file names
- [ ] Lowercase with hyphens
- [ ] Include keywords when relevant
- [ ] No spaces or special characters

**Good:** scaffolding-installation-sydney.jpg
**Bad:** IMG_1234.jpg

---

## Internal Linking

### Link Structure
- [ ] 5-8 internal links per page (content-dependent)
- [ ] Links to relevant, related content
- [ ] Descriptive anchor text
- [ ] Varies anchor text (no repetition)
- [ ] Links high-priority pages
- [ ] No broken internal links
- [ ] Deep links (not just homepage/top pages)

### Anchor Text Best Practices
- [ ] Descriptive and natural
- [ ] Includes keywords when appropriate
- [ ] Varies across site
- [ ] Never "click here" or "read more"
- [ ] Context around link provides clarity
- [ ] Not overly optimized

**Good:** "professional scaffolding services"
**Bad:** "click here" or "scaffolding scaffolding scaffolding"

### Strategic Linking
- [ ] Link to cornerstone content
- [ ] Link from high-authority pages
- [ ] Create topic clusters
- [ ] Link to conversion pages
- [ ] Avoid orphan pages

---

## External Linking

- [ ] Links to authoritative sources
- [ ] Links add value for readers
- [ ] Links to relevant resources
- [ ] Links open in new tab (user preference)
- [ ] No broken external links

## Page Speed

### Performance Targets
- [ ] LCP (Largest Contentful Paint) < 2.5s
- [ ] FID (First Input Delay) < 100ms
- [ ] CLS (Cumulative Layout Shift) < 0.1
- [ ] Page load time < 3 seconds
- [ ] Mobile and desktop optimized

### Speed Optimization
- [ ] Images compressed
- [ ] Lazy loading images
- [ ] Minified CSS/JS
- [ ] Browser caching enabled
- [ ] GZIP compression enabled
- [ ] CDN (if applicable)
- [ ] Reduce redirects
- [ ] Optimize web fonts
